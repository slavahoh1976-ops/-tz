WINCH CONTROL 1.09 — пульт для DMX-лебёдок ES-L32 по Art-Net

ЗАПУСК
  Windows (готовая сборка): распакуйте архив и запустите WinchControl_v1.09.exe.
           Python не нужен. Пульт откроется отдельным окном (Edge/Chrome).
           При первом запуске Windows может спросить про брандмауэр — разрешите
           (частные сети), иначе не будет работать Art-Net. Если SmartScreen
           предупредит о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».
  Windows (из исходников): двойной клик «Запуск Windows.bat»  (нужен Python 3 с python.org, галочка «Add to PATH»)
  Mac:     двойной клик «Запуск Mac.command»   (первый раз: правый клик → Открыть)
  Пульт откроется в браузере. Окно консоли не закрывать — это и есть программа.
  Управление с iPad/телефона: python winch_control.py --lan (адрес напишется в консоли).

ПЕРВАЯ НАСТРОЙКА (вкладка «Настройки»)
  1. Art-Net: IP узла/контроллера или broadcast своей сети (напр. 192.168.1.255, 2.255.255.255).
     Если сетевых карт несколько — выберите нужную.
  2. Библиотека приборов: встроены EastSun ES-L32 5CH (16 бит, плавнее) и 4CH (8 бит),
     универсальные лебёдки 8/16 бит. Другую модель — «+ Новый прибор» или «⧉» (копия)
     по таблице каналов из инструкции: назначение каждого канала (Safety, позиция грубо/fine,
     позиция 8 бит, скорость с инверсией, Reset, постоянное значение) и его значения.
     Режим на самих лебёдках должен совпадать с выбранным прибором.
  3. Патч: прибор, количество, universe, стартовый адрес → «Авто-патч». Прибор можно
     менять у каждой лебёдки отдельно. Колонок — как висят лебёдки.
     Для каждой: инверсия направления, Предел ↑ / Предел ↓ (зона, за которую лебёдка
     не заходит — ни вручную, ни в эффектах, ни по таймкоду), точка Home.
     Задавать удобнее по выставленной лебёдке — вкладка «Пределы»:
       выделить лебёдку/экран → «Начать настройку» (старые пределы временно сняты) →
       удерживая ▲ довести до крайнего верха → «Запомнить верх» →
       удерживая ▼ опустить до крайнего низа → «Запомнить низ» → «Готово».
       Кнопки ▲/▼ — медленно, ▲▲/▼▼ — быстро, короткое нажатие — шаг 0,1%, клавиши ↑ ↓.
       Галочка «отдельные лебёдки внутри экрана» — чтобы выровнять экран по каждой лебёдке.
  4. Экраны: лебёдки одного экрана связываются в объект («⛓ Связать» или
     «Настройки → Экраны → Собрать по порядку», схема вроде 2,3,2,2,3).
     Экран выделяется и движется целиком, волна идёт по экранам, а не по лебёдкам.
     У экрана действует самый строгий предел его лебёдок — он не перекашивается.

РАБОТА
  • «МОТОРЫ ВЫКЛ/ВКЛ» — канал Safety (130 = вкл). При запуске моторы всегда выключены.
  • Шарики можно тянуть мышью (двигаются все выделенные), двойной клик — сразу в точку.
  • Пресеты: записать/вызвать (клавиши 1–9), время перехода у каждого.
    Работающие эффекты записываются в пресет («с эффектами») и запускаются при вызове
    (плавно, за время перехода) — в том числе из шоу и по таймкоду.
    Кнопка TC на плитке пресета — время запуска по таймкоду (можно несколько через запятую).
  • Эффекты (16): Волна, Дыхание, Бегущая капля, Маятник, Стоячая волна, Хаос, Домино,
    Наполнение, Мячики, Пульс, V↔Λ, Качели, Из центра, Рябь, Течение, Чёт/нечёт —
    на выделенных/группе; ползунки меняют запущенный эффект вживую.
  • В эффектах: «Скорость эффекта» 10–400% (меняется на ходу, показан цикл в секундах)
    и «Скорость моторов» — канал скорости лебёдок в эффекте (0 = не менять).
  • Формы: V, Λ, наклон, синус, дуга, шахматы — выстроить за N секунд.
  • Шоу: цепочка пресетов с переходами и паузами, GO по клавише G.
  • Таймкод: события по времени — пресет, шоу, эффект, стоп, домой.
    Источники: Art-Net Timecode (порт 6454: Resolume, grandMA, Madrix, ShowKontrol…),
    LTC со звукового входа (линейный вход/микрофон компьютера, канал L или R;
    вкладку пульта держать открытой — декодирование идёт в ней) и внутренние часы для репетиций.
    «Начало шоу» — смещение (например, 01:00:00:00). «Догонять» — после перемотки сразу
    выполняется последнее прошедшее событие. Клавиша T — записать событие на текущем TC.
  • Каналы: скорость мотора (100% = DMX 1, самый быстрый), Reset (248), монитор DMX.
  • 3D-вид: переключатель 2D / 3D над сценой. Мышь — вращать, колесо — масштаб,
    правая кнопка или Shift — сдвиг, клик — выделить экран/лебёдку. Виды: 3/4, спереди,
    сбоку, сверху. «⚙ Размеры» — высота фермы, ход, шаг лебёдок, ряды, высота экрана (м).
  • «✥ Расставить» (в 3D): экраны и лебёдки ставятся в любую точку — тянуть мышью
    (шаг 5 см, Alt — без шага): вид Сверху и 3/4 — по площадке X/Z; Спереди — X и высота
    подвеса; Сбоку — глубина Z и высота. Виды Спереди/Сбоку/Сверху — без перспективы.
    Или ввести X, Z, Y (высота подвеса) и угол. Раскладки: линия, дуга, круг,
    2 ряда, разброс, «по сетке». Эффекты «слева направо», «спереди назад», «от центра»
    идут по реальным координатам.
  • Сцена: «В ряд» — сколько лебёдок в ряду, «Ширина» — ширина ячейки («Авто» — под окно).
  • Space — СТОП (всё замирает на месте), Esc — снять выделение, Ctrl+A — все.

ШОУ (кнопка 📁 вверху, Ctrl+O; Ctrl+S — сохранить)
  Каждое шоу — отдельный файл в папке Shows рядом с программой, открытое сохраняется само.
  Новое (можно взять патч, экраны и группы из текущего), Открыть файл…, Сохранить,
  Сохранить как…, Последние, все шоу папки (переименовать, копия, удалить → Shows/Удалённые),
  Экспорт .json, Открыть пример. При смене шоу моторы выключаются.
  При первом запуске 1.08 открывается «Пример 3D»: 10 экранов на 23 лебёдках по кругу, вид 3D.
  Шоу из версий до 1.05 (winch_show.json) переносится в Shows/«Моё шоу».
При закрытии программа сначала выключает Safety.
