# Winch Control

Art-Net пульт для DMX-лебёдок (EastSun ES-L32 и другие): пресеты с эффектами, экраны из связанных лебёдок,
шоу, таймкод (Art-Net TC / LTC), пределы по выставленной лебёдке, библиотека приборов.

Ветка `winch-control` — исходники и автоматическая сборка Windows (`.github/workflows/winch-control-build.yml`).
Готовые версии — в Releases с тегами `winch-v*`.
