LMG Sans — урезанная (только латиница, кириллица и нужные знаки) и переименованная копия
шрифта Liberation Sans 2.1.5 (метрики совпадают с Arial). Переименована по требованию лицензии
SIL Open Font License 1.1 (зарезервированное имя «Liberation»). Лицензия — LICENSE-Liberation-OFL.txt.
Используется программой для текста ТЗ и подписей, чтобы в PDF текст шёл в кривых.

LMG Mask P/F/S/L/Y/C/J/I — урезанные (латиница, кириллица, нужные знаки; обычный и жирный) копии свободных
шрифтов под SIL Open Font License 1.1 для надписей на масках: PT Sans (ParaType), Fira Sans, Source Sans 3 (Adobe),
Lato, Ysabeau Office, Scada, Jost, Istok. Шрифты с зарезервированными именами (PT Sans/ParaType, Source, Lato,
Istok) внутри переименованы. Лицензии — LICENSE-*-OFL.txt. Пересборка: tools/mkfonts.py.
