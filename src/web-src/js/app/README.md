# Программа по частям

Раньше вся программа была одним файлом `app.js`. Теперь она разложена по разделам —
так проще находить нужное место и вносить правки. Сборщик (`python build_web.py`)
склеивает все `.js` из этой папки **по порядку имён** в один общий скрипт —
в готовом `index.html` всё как раньше, Web / Windows / Mac / Android работают одинаково.

Правила:
- Порядок файлов важен (01-…, 02-…): склейка идёт по номерам, как один большой файл.
  Новый кусок — новым номером в нужном месте (например `17a-…` или перенумеровать).
- Все файлы — один общий скрипт: функции и переменные видны из любого файла,
  `import` / `export` не нужны (и не используются — их не понимает старый Mac WebKit).
- Перед сборкой каждый файл проверяется `node --check` (если установлен Node.js);
  при ошибке сборка останавливается и показывает файл и строку.
